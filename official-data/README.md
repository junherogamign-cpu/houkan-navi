# 訪問看護制度ナビ公式データ

## 共通形式

各JSONは次の形式で管理します。

```json
{
  "schemaVersion": "1.0.0",
  "informationAsOf": "YYYY-MM-DD",
  "records": []
}
```

公式資料から作成する各レコードには、`source`、`sourceUrl`、`documentName`、`publishedDate`、`effectiveDate`、`informationAsOf`、`page`、`verified`を付けます。日付やページを資料から確認できない場合は推定せず、空文字または`null`にします。Q&Aでは質問と回答を資料の範囲で記録し、一次資料で回答を確認できない場合は`verified: false`とします。

## 収録方針

- 訪問看護の制度判定に直接必要な範囲だけを収録します。
- PDF全体は取り込まず、訪問看護に該当する条項・Q&Aだけをレコード化します。
- 未確認カテゴリは空の`records`配列のままにし、推測による補完をしません。
- 既存の判定エンジン`js/rules.js`とは分離したデータです。現時点では実行時照合に接続していません。
- `informationAsOf`はこのデータセットの確認日です。個別資料の発出日・適用日は各レコードに記録します。
